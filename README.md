# Aegis Pix

Para cada solicitação de transação financeira, existe uma janela para o aceite ou a recusa por parte da operadora financeira — bancos, fintechs, entre outros.

**O cerne de toda essa questão é: como diferenciar uma transação fraudulenta de uma legítima?**

Ao impedir uma transação fraudulenta e aprovar uma legítima, obtém-se o melhor dos dois mundos — e para isso seria preciso um modelo perfeitamente ajustado, sem underfitting e nem overfitting.

A proposta deste exercício é, com base em informações públicas devidamente referenciadas, criar duas bases sintéticas:

- **Base A** — para compreender, por meio de ferramentas matemáticas e estatísticas, a dinâmica levantada.
- **Base B** — gerada de forma independente com a mesma estrutura, para validar se os padrões identificados na primeira realmente se sustentam fora da amostra em que foram descobertos.
